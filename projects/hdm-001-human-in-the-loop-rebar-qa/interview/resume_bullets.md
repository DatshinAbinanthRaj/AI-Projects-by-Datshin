# Resume bullets (independent portfolio project)

- Built a human-in-the-loop QA prototype in Python that checks rebar schedules with nine validation rules and routes each row to auto-accept, auto-flag or human review, with an append-only SQLite audit trail of reviewer decisions.
- Designed the QA measurement around quality sampling, false-alarm rate per rule and escape rate, and verified the workflow with 28 automated tests and a synthetic dataset with known injected defects.

Describe this as a personal portfolio project, not paid work.
