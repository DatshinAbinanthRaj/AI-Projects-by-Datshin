# AI Projects by Datshin

A long-running portfolio of small, working AI and Human Data Management projects: data quality, annotation QA, LLM evaluation, AI operations, and AI applied to rebar detailing and BIM. The plan is 600 projects, added one at a time.

Each project lives in its own folder under `projects/`, runs on its own, and includes sample data, tests and documentation. All data is synthetic or publicly licensed. The projects are built with AI assistance as a learning and portfolio exercise.
